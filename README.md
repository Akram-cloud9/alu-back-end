# ALU Back-End

## Project: API

This project contains a Python script that retrieves employee information and TODO list progress from a REST API.

### Task 0: Gather data from an API

File: `api/0-gather_data_from_an_API.py`

The script accepts an employee ID as a command-line argument and displays the employee's completed tasks and total tasks.

### Requirements

- Python 3
- urllib
- JSON
